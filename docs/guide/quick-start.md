# 快速开始

will 支持免注册免费试用，也可以注册账号解锁完整功能。

## 第一步：打开网页版

访问 [https://chat.willbe.wang/](https://chat.willbe.wang/)，或直接打开 [官网](https://willbe.wang/) 点击「立即体验」。

## 第二步：试用或注册

- **免注册试用**：首页通常提供免注册的试用入口，点进去即可体验部分功能
- **注册账号**：注册后可以使用完整模型列表、历史记录和多端同步

## 第三步：选择模型开始对话

在模型列表中选择想用的模型：

- 写方案、写长文 → GPT / Claude
- 中文创意、文案 → Kimi / DeepSeek
- 多模态需求 → Gemini

## 第四步：下载客户端（可选）

如果需要 Windows 或安卓端，可以从 [下载页](https://willbe.wang/downloads/ios.html) 获取安装包。
