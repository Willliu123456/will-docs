# 多模型平台怎么用

不同大模型各有所长。写方案用 GPT，中文创意用 Kimi，长文分析用 Claude——但如果每个平台都要单独注册充值，成本很高。多模型平台就是为了解决这个问题。

## 主流模型适合什么场景

| 模型 | 适合场景 |
|---|---|
| GPT | 综合能力强，写方案、写代码、逻辑推理 |
| Claude | 长文本处理、深度分析、写作润色 |
| DeepSeek | 中文理解好，性价比高，推理任务 |
| Kimi | 中文创意、文案、长文本阅读 |
| Gemini | 多模态能力，图文混合任务 |

## 在 will 里切换模型

1. 打开 [网页版](https://chat.willbe.wang/) 或 [官网](https://willbe.wang/)
2. 注册 / 登录账号
3. 在对话界面的模型列表中选择想用的模型
4. 直接开始对话，切换模型不需要重新注册

## 为什么要一个账号用多个模型

- **省钱**：不用给每个平台单独充值
- **省事**：不用记多套账号密码
- **灵活**：不同任务用最合适的模型，效果更好
- **全端同步**：网页、Windows、安卓端数据互通
